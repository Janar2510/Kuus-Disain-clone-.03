## How the styling was captured

`src/app/senawa.css` is generated by `scripts/build-senawa-css.py` from the
site's own stylesheets (`docs/research/senawa/source-globals.css` and
`styles.css`). Module hashes are rewritten to short prefixes
(`Nav-module__bLoQaq__nav` → `nav-nav`), so components use the source's real
rules rather than approximations. Re-run the script to regenerate.

Fonts are the source's real Inter and Sora woff2 subsets (`public/fonts`).

## Assets

- `public/sites/senawa/work/<slug>/NN.jpg` — 152 project photographs pulled at
  1920px from the site's image CDN, in page order (00 = cover).
- `public/sites/senawa/studio/` — studio mark plus nine team silhouette masks.
- `public/videos/` — the AA House and AM House films (720p) used as the first
  gallery frame.
- `docs/research/senawa/dom/` — per-route DOM outlines used while building.

## Motion

The source drives motion with CSS classes plus view transitions. Here the same
timings and easings are expressed with framer-motion:
scroll reveals (`Reveal`), 1.2s image fades (`FadeImage`), the draggable home
carousel with wheel and arrow keys (`ProjectCarousel`), the route shutter
(`PageTransition`), drawer/search overlay, grid ↔ index switch, the element
mosaic panel, and the gallery/portrait carousels.

## Known gaps

- The source's element mosaic uses JS-computed crop geometry and a hover
  proximity system; this build uses a fixed five-cell mosaic with the same
  lock/panel behaviour.
- Only AA House and AM House publish a film on the source; other projects show
  stills, as they do there.
- No backend for the contact form: submission is acknowledged locally, exactly
  like the reference form's success state.
